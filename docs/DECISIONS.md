# Решения

Короткие записи, чтобы следующие файлы им не противоречили. Менять решение — править этот файл и README в том же шаге.

## Доступ к Grafana и Prometheus — SSH-туннель

Сервисы слушают только `127.0.0.1` на VPS. С ноутбука их видно через `ssh -L`. В интернет порты 3000, 9090 и 9093 не публикуются.

Почему так, а не Nginx с паролем:

- Меньше частей. Отдельный Nginx, файл паролей и сертификат легко настроить криво.
- Пароль basic auth — ещё один секрет. Его так же легко случайно закоммитить.
- Для учебного портфолио важно показать границу: метрики не торчат в сеть. Туннель как раз про эту границу.
- Alertmanager ходит в Telegram сам, исходящим подключением. Ему не нужен входящий порт из интернета.

Nginx с паролем имеет смысл позже, если дашборд понадобится открыть по ссылке без SSH. В этот проект он не входит.

`node_exporter` на хост не пробрасываем вообще. Его читает только Prometheus по внутренней сети Docker.

## Пороги

Порог — это «уже стоит посмотреть», не «сервер сейчас умрёт». Короткий всплеск не должен будить Telegram, поэтому у каждого правила есть `for`.

| Алерт | Порог | Ждём | Почему так |
|---|---|---|---|
| InstanceDown | цель `up == 0` | 1 мин | Экспортёр не отвечает: процесс упал или сервер недоступен. Минута, чтобы не орать на перезапуске контейнера. |
| HighCpu | больше 85% | 5 мин | Краткий пик на деплое нормален. Пять минут подряд — загрузка держится. |
| HighMemory | больше 90% доступной памяти занято | 5 мин | Считаем `MemAvailable`. Кэш Linux не считаем занятой памятью, иначе алерт врёт. 90% — приложению уже тесно. |
| HighDisk | занято больше 85% | 10 мин | До 100% ещё есть место почистить логи. Десять минут, чтобы не ловить момент записи большого файла. |
| HighLoad | load за 1 мин выше числа ядер | 5 мин | Load 1.0 на одно ядро значит, что очередь задач насыщена. Выше числа ядер — сервер не успевает. |

Severity: `critical` у InstanceDown и HighDisk (сервер слепой или скоро некуда писать). Остальные — `warning`.
