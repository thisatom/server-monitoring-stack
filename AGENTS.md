# Как агенту работать в этом репозитории

Учебный проект: мониторинг одного VPS (Debian 12) для портфолио DevOps. Стек ещё не собран. Сейчас в репозитории фундамент: правила, хук, навык и документы.

## Что делать

1. Объяснять шаги простым русским языком. Человек учится, не принимает «магию YAML».
2. Держать план в `docs/PLAN.md`. Следующий файл — один за раз, в порядке из плана.
3. Перед правками стека читать навык `.cursor/skills/monitoring-stack/SKILL.md` и `docs/DECISIONS.md`.
4. Секреты не писать никуда, кроме `.env` на сервере. Образец — `.env.example`.
5. Проверять Docker только на VPS. На компьютере автора Docker не работает, выдуманный вывод команд запрещён.

## Чего не делать

- Не публиковать Grafana, Prometheus и Alertmanager на `0.0.0.0`.
- Не ставить тег образа `latest`.
- Не добавлять Nginx, пока отдельно не попросят. Доступ — SSH-туннель.
- Не менять пять алертов и их пороги молча.
- Не коммитить, пока не попросили.
